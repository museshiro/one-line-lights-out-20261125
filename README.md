## The line

> Lights out. The fan is still spinning down, and the cursor is holding your place in a sentence you left half-typed.

## How it works

`main.ts` writes the line above to `/output/entry.txt` — nothing else, no network, no clock, no randomness. The output is byte-identical on every run.
